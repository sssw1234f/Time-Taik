# 📜 타임톡(Time-Talk)
> **대한민국역사박물관 오픈아카이브 데이터 기반 AI 역사 페르소나 챗봇 & 맞춤형 학습 플랫폼**  
> *교육·학습을 위한 AI 공모전 출품작 (MVP)*

---

## 🌟 프로젝트 개요
**타임톡(Time-Talk)**은 역사적 인물(유관순, 안중근, 윤봉길 등)과의 대화를 통해 학생들의 자기주도적 역사 탐구를 유도하고, 실시간 공공 사료(위키미디어·역사박물관 아카이브) 교차 검증 및 교사용 맞춤형 활동지(PDF/Markdown)를 원클릭으로 생성해주는 차세대 에듀테크 서비스입니다.

---

## 🚀 빠른 시작 (Quick Start)

### 1. 환경 설정 및 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. API 키 설정 (선택 사항)
- `.env.example`을 복사하여 `.env`를 생성하고 Gemini API 키를 입력하거나,
- **API 키 없이도 앱 내 데모 모드로 즉시 모든 기능과 프리셋을 체험**할 수 있습니다.
- 앱 실행 후 사이드바에서 직접 API 키(1차/2차 페일오버 지원)를 입력할 수도 있습니다.

```env
GEMINI_API_KEY_1=AIzaSyYourFirstApiKeyHere
GEMINI_API_KEY_2=AIzaSyYourSecondApiKeyHere
```

### 3. 애플리케이션 실행
```bash
streamlit run app.py
```
브라우저에서 `http://localhost:8501`이 자동으로 열립니다.

## 🎯 핵심 기능 시연 가이드 (Key Demo Features)

1. **⚡ 지능형 Q&A 캐싱 레이어 (Cache-Aside 패턴)**
   - 동일하거나 유사한 질문 인입 시 외부 LLM API를 중복 호출하지 않고 SQLite DB에서 즉시 반환.
   - **Cache HIT:** `⚡ 초고속 즉시 답변 (캐시 적용됨)` 뱃지 노출, API 비용 0원 & 응답시간 0초.
   - **Cache MISS:** `🧠 실시간 AI 생성 완료 (DB 저장됨)` 뱃지 노출 후 신규 Q&A 자동 영속화.
   - 사이드바에서 "저장된 Q&A 수" 및 "절약된 API 호출 수" 메트릭 실시간 확인 가능.

2. **💡 원클릭 질문 프리셋 (Demo Presets)**
   - 타이핑 없이 인물 소개 하단의 **추천 질문 칩 버튼**을 클릭하여 즉시 시연 가능.
   - 인물별(유관순, 안중근, 윤봉길)로 엄선된 핵심 역사 질문 제공.

3. **⚡ 실시간 스트리밍 & 단계별 사료 검증 피드백**
   - 질문 전송 시 페르소나 분석 ➔ 아카이브 사료 검색 ➔ 실시간 텍스트 타이핑 효과로 이어지는 몰입감 있는 UX.

4. **📷 공인 사료 이미지 실시간 매칭**
   - 대화 맥락 속 핵심 장소/사건/유물을 추출하여 위키미디어 공공 아카이브의 엄격 검증된 사료 사진을 자동으로 함께 표출.

5. **📝 교사용 수업 활동지 원클릭 생성 & PDF 다운로드**
   - 좌측 사이드바의 **[📝 교사용 활동지 생성]** 버튼을 클릭하면 초·중·고 수준별 토론 질문, 팩트 퀴즈, 메타인지 기록장이 포함된 활동지가 모달 팝업으로 열리며 PDF/Markdown으로 즉시 다운로드 가능.

## 🛡️ 안정성 및 아키텍처
- **Cache-Aside 패턴:** DB 조회 실패나 네트워크 오류 시에도 자동으로 LLM 직접 호출로 Fallback되어 100% 가용성 보장.
- **다중 API Failover:** 1차 API 키 할당량 초과 시 2차 키로 자동 전환.
- **캐싱 최적화:** `@st.cache_data` 및 `@st.cache_resource`로 위키미디어 API 호출 및 폰트 로딩 병목 제거.
- **반응형 UX:** 모바일 숏폼 뷰 및 다양한 해상도에 맞춘 `keep-all` 한글 줄바꿈 및 스크롤바 억제 CSS 적용.
- **보안 철저:** `.gitignore`를 통한 민감 키 및 임시 파일 유출 차단.
